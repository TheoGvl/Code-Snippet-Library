# Code Snippet Library

A modern desktop application built with Python and **CustomTkinter**, designed to store, manage, and filter code snippets efficiently during your workflow. 

This project was developed to explore and showcase modern Python UI development, demonstrating a native desktop alternative to web-engine frameworks (like Flet). It focuses on a clean, responsive, and user-friendly aesthetic.

## Features

* **Modern Interface:** Built completely with `customtkinter` for a sleek, contemporary look.
* **In-Memory Storage:** Save and retrieve code snippets on the fly without needing an external database setup.
* **Language Filtering:** Categorize snippets by programming language (Python, C++, HTML, SQL, JavaScript) and filter them dynamically via the sidebar dropdown.
* **Quick Copy:** One-click "Copy Code" functionality with instant visual feedback.
* **Snippet Management:** Easily clear the editor canvas or permanently delete snippets you no longer need.

## Installation & Usage

1. **Clone the repository:**
   ```
   git clone https://github.com/theogvl/code-snippet-library.git
   ```

2. **Install dependencies:**
   Make sure you have Python installed, then install the required UI library:
   ```
   pip install customtkinter
   ```

3. **Run the application:**
   Navigate to the project folder and run:
   ```bash
   python Code_Library.py
   ```
   *(Note: Ensure your main script is named `Code_Library.py`, or replace it with your file's actual name).*
